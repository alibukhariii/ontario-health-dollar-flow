# Contributing

Corrections are welcome when they include a public source and identify the affected fiscal year, published label, program or statement line.

Before opening a pull request:

1. Add or update a test that fails before the change.
2. Preserve exact source-native labels in the raw contract.
3. Do not merge payees without authoritative identity evidence.
4. Do not add personal labels, raw source PDFs or internal review files.
5. Run `npm test` and `npm run build`.

For taxonomy changes, explain why the source program belongs in the proposed funding purpose and confirm that all 14 categories still reconcile to the positive-payment total.
